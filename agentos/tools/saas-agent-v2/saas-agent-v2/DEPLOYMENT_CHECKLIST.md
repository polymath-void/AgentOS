# ✅ SaaS-Agent v2 Deployment Checklist

**Verify all items before pushing to production.**

---

## Local Testing (Before Git Push)

- [ ] **Python 3.11+** installed: `python --version`
- [ ] **Virtual environment created**: `venv/` directory exists
- [ ] **Dependencies installed**: `pip list | grep google-genai`
- [ ] **No syntax errors**: `python -m py_compile *.py`
- [ ] **All imports work**: `python -c "from main import app"`

---

## Configuration & Secrets

- [ ] **GEMINI_API_KEY set**: `echo $GEMINI_API_KEY` (not in git!)
- [ ] **.env is in .gitignore**: `cat .gitignore | grep .env`
- [ ] **No hardcoded keys** in source code: `grep -r "gemini-" *.py` (empty result = good)
- [ ] **Database path configurable**: Uses `~/.saas_agent/cards.db` (environment-configurable)

## Functionality Tests

Run locally to verify core features:

```bash
# Start server
python main.py &

# Health check
curl http://localhost:8000/health

# List cards
curl http://localhost:8000/cards

# Test chat endpoint
curl -X POST http://localhost:8000/chat \
  -H "Content-Type: application/json" \
  -d '{"task":"what time is it","local_context":{}}'

# Test PWA loads
curl http://localhost:8000 | head -20
```

- [ ] **Health check returns ok**
- [ ] **Cards endpoint lists pre-seeded cards**
- [ ] **Chat endpoint responds (no 500 errors)**
- [ ] **PWA serves HTML (200 status)**
- [ ] **Service Worker registers** (check browser DevTools → Application)
- [ ] **Chat UI loads** in browser at `http://localhost:8000`
