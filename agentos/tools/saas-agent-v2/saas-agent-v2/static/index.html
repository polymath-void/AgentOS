✦ Features

Everything you need to automate

20+ built-in tools, intelligent card routing, and the ability to create your own AI agents on the fly.

🎯

Smart Intent Routing

Your message is automatically classified and routed to the best specialized agent card — media, files, email, calendar, or system control.

🛠️

20+ Built-in Tools

YouTube playback, file management, SMS, call logs, Gmail, Google Calendar, notes, brightness control, WiFi toggle, and more.

Create Custom Agents

Describe what you want in plain English. The AI generates a specialized agent card with its own system prompt, tools, and behavior.

Model Fallback

Automatic fallback across Gemini models. If one is busy, your request seamlessly routes to the next available model — zero downtime.

Works as a Progressive Web App. Install on your phone's home screen for a native app experience with offline support.

Secure by Design

JWT authentication, server-side API key storage, rate limiting, and input validation on every request. Your data stays yours.
