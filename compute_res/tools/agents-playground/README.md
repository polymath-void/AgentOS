# Neural Agent Network

Welcome to the **Neural Agent Network** engine. This project provides a robust, distributed environment for autonomous agents to operate, communicate, and remember past interactions.

## Overview

The engine is built around three core components:

1. **P2P Mesh**: A decentralized peer-to-peer network for agent communication.
2. **Episodic Memory**: A memory subsystem allowing agents to recall and reason about past events.
3. **WASM Actors**: Lightweight, secure execution environments for agent logic.

For a detailed breakdown of how these systems interact, please see the [Architecture Documentation](docs/architecture.md).
