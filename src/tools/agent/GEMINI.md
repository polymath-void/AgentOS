# Project Mandates

- **Stack:** Production-grade binary, written in Rust, leveraging the `tokio` asynchronous runtime.
- **Environment:** Native `aarch64` target for Android/Termux.
- **Documentation:**
  - All agents MUST keep `CONTEXT.MD` and `AGENTS.MD` updated after every major architectural change or workflow adjustment.
  - Failure to update documentation is a violation of project standards.
- **Workflow:** Prioritize performance, memory safety, and seamless IPC integration.
